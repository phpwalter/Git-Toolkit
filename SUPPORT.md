# <img src="../docs/assets/toolkit-icon.png" alt="Description" width="30"/> Support Policy – Git Toolkit

Thank you for using the **Git Toolkit** project!

This document explains where and how to get help, ask questions, or report usage issues related to Git Toolkit—whether you're a developer, contributor, or just exploring.

---

## 📬 Where to Ask for Help

If you need assistance:

### 🐛 Bug or Behavior Issue?
- 👉 [Open an Issue on GitHub](https://github.com/phpwalter/Git-Toolkit/issues/new?assignees=&labels=bug&projects=&template=bug_report.md&title=%5BBug%5D+)
- Be sure to include:
    - Git Toolkit version
    - Python version
    - Operating System
    - Steps to reproduce
    - Expected vs actual behavior
    - Relevant `.git-toolkit.yml` snippets or CLI usage examples

### 💡 Feature Request or Enhancement?
- 👉 [Submit a Feature Request on GitHub](https://github.com/phpwalter/Git-Toolkit/issues/new?assignees=&labels=enhancement&projects=&template=feature_request.md&title=%5BFeature%5D+)
- Explain your use case clearly so we can assess alignment with project goals and the [Roadmap](./ROADMAP.md).

### ❓ General Usage or Integration Help?
- Check the [FAQ](./FAQ.md)
- Review the [Integration Guide](./INTEGRATION.md)
- Explore the [Documentation Summary](../docs/en/SUMMARY.md)
- If your question isn't answered, consider [opening a discussion on GitHub](https://github.com/phpwalter/Git-Toolkit/discussions).

---

## 📄 Before Submitting an Issue

Please confirm that:

- You are running a [supported version](./RELEASE.md) of Git Toolkit.
- You’ve reviewed the [CHANGELOG.md](./CHANGELOG.md) for recent changes.
- You’ve checked the relevant [documentation](../docs/en/).
- You’ve searched existing [GitHub Issues](https://github.com/phpwalter/Git-Toolkit/issues) and [Discussions](https://github.com/phpwalter/Git-Toolkit/discussions) to see if your question has already been addressed.
